- **Status**: Federal Non-Profit Corporation in Canada

---

## 🛠 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Language**: TypeScript 5 / React 19
- **Fonts**: Playfair Display (Serif) + Inter (Sans) via `next/font/google`
- **Contact API**: `/api/contact` (Next.js route handler)

---

## 🚀 Getting Started

First, install dependencies (if not already installed):

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

---

## 📦 Build & Deploy

Build the production bundle:

```bash
npm run build
```

Deploy directly with Vercel CLI:

```bash
vercel --prod
```
